# Règles pour les IA

Ce dépôt est la source de données commune.

## ChatGPT
- Peut lire tous les fichiers.
- Ne doit pas écrire de stratégie, décision, score propriétaire ou portefeuille proposé ici.
- Écrit ses stratégies dans `strategie-chatgpt`.
- Peut lire `strategie-claude` pour comparer les résultats.

## strategie-claude
- Peut lire tous les fichiers.
- Ne doit pas écrire de stratégie, décision, score propriétaire ou portefeuille proposé ici.
- Écrit ses stratégies dans `strategie-claude`.
- Peut lire `strategie-chatgpt` pour comparer les résultats.

## Données communes
Seuls les workflows automatiques et Olivier doivent modifier les données communes.

## Confidentialité
Ne jamais ajouter : nom de famille, e-mail, adresse, téléphone, numéro de contrat, identifiant client, document contractuel brut, valeur exacte du contrat ou autre donnée permettant d'identifier Bernard.

Le prénom Bernard est un alias autorisé. Les montants sont remplacés par des pourcentages ou une base 100.
