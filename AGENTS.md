# Règles pour les IA

Ce dépôt est la source de données commune.

## ChatGPT
- Peut lire tous les fichiers.
- En exploitation normale, ne doit pas écrire de stratégie, décision, score propriétaire ou portefeuille proposé ici.
- Écrit ses stratégies dans `strategie-chatgpt`.
- Peut lire `strategie-claude` pour comparer les résultats.
- Peut modifier l'infrastructure de ce dépôt uniquement si Olivier le demande explicitement.

## Données communes
Les mises à jour régulières sont faites par les workflows automatiques. Olivier reste administrateur du dépôt.

## Confidentialité
Ne jamais ajouter : nom de famille, e-mail, adresse, téléphone, numéro de contrat, identifiant client, document contractuel brut, valeur exacte du contrat ou autre donnée permettant d'identifier Bernard.

Le prénom Bernard est un alias autorisé. Les montants sont remplacés par des pourcentages ou une base 100.

## Important
Cette règle est une règle d'usage. Pour un cloisonnement technique strict, chaque IA devra utiliser des identifiants GitHub distincts avec permissions limitées sur son propre dépôt de stratégie.
