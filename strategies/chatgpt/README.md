# Stratégies ChatGPT

Trois logiques distinctes sont suivies :

- **Impulsion** : concentration sur les leaders de tendance.
- **Adaptative** : niveau de risque variable selon le régime de marché.
- **Rotation diversifiée** : force relative avec contraintes de concentration et de corrélation.

Chaque stratégie possède sa propre version, ses décisions datées, son portefeuille courant et son historique de performance.
